# Open-course full curriculum package

This package expands the ten source syllabi into week-level instructional content using the same course-content JSON pattern as the earlier Grade 7–12 curriculum package.

## Structure
- `course`: course metadata
- `course_learning_outcomes`: course outcomes
- `modules`: phase/module records with `weeks`
- `weeks`: warm-ups, instructor overview, learning objectives, lesson content, vocabulary, practice, assignment, and weekly quiz metadata
- `module_test`: module assessment metadata and coverage
- `standalone_weeks`: integrated benchmark weeks outside numbered modules (where the source schedule uses them)
- `pathways`: parallel Phase II curriculum branches for Cosmetology, Esthetics, and Nail Technology in Salon & Spa Management

## Important
The course titles, module/phase sequence, source topics, durations, and source-specified assessment details are retained. Week-level lesson sequences and learning activities are authored instructional expansions. They should be reviewed by qualified trade instructors and aligned to the applicable jurisdiction's current licensing, code, safety, and scope-of-practice requirements before student delivery. Question-level quiz/test items and answer keys are not included; quiz and test records define coverage and assessment metadata.
